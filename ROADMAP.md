# Roadmap

Assay is intentionally local-first. The roadmap favours a small, trustworthy
tool over a broad but shallow one.

## Next

- Finish the local packaging path: one binary, free-port selection, browser
  launch, and macOS/Windows builds.
- Add browser smoke tests and a golden end-to-end study fixture.
- Complete `docs/primitives.md` coverage for every registered primitive.
- Make the Setup Test and event-study surfaces usable without a terminal.
- Add signed release artefacts and a reproducible release workflow.

## Later

- Native desktop wrappers for macOS and Windows.
- Equities and corporate actions (batch 14).
- More venue adapters, subject to redistribution terms.
- Hosted, multi-user operation only after authentication, per-user isolation,
  quotas and a data-rights review exist.

## Not planned

- Live trading, broker credentials, or order routing.
- Machine-learning strategy generation.
- Presenting historical results as forecasts.
